### 真机验收清单（用户操作）

1. 头部强度下拉切「错别字」→ 检查一段：应只出错别字/标点类建议；切「润色」再查：建议更激进
2. 底部输入「压缩到 50 字以内」→ 运行：改写预览流式出现文字，完成后变红删绿增 diff → 应用 → Ctrl+Z 可撤销；`.exeditor/backups/` 出现改写前快照
3. 全文检查出一批建议 → 「接受全部（N）」：一次 Ctrl+Z 全部撤销；快照目录出现 accept 快照
4. 展开「快照与恢复」→ 立即备份 / 选一条恢复：恢复后内容回滚，且恢复前版本也被快照
5. 修改被建议的原文：对应卡片自动灰显；批量接受时灰显项被跳过
6. 词级 diff：含英文单词替换的建议卡片应显示整词红删绿增（不出现 be~~caus~~ome 式碎片）；改写预览同理
7. 取消：思考阶段（「思考中…」字样出现时）点任务行红色 × → 应 1 秒内该任务消失、无新请求（此前会重发一个取消不掉的非流式请求）；改写运行中底部发送按钮应变红色「取消改写」，点击即中断；顶栏「检查」始终可用
8. 改写体验：发起改写后预览面板立即出现且初始为空，随输出逐句出现红删绿增 diff（不再满屏红）与进行光标；滚动到底部时应跟随输出；改写结果不应出现 `<article>` 等包裹标签（出现即剥离失效，需报告）
9. 隐藏删除：点列表头或改写预览的 eye 按钮 → 全部 diff 只显示绿色新增，再点恢复
10. 多任务并行：对同一文件连续检查两个不同段落 → 任务区应出现两行任务（各自进度、各自 × 可单独取消）；切到另一文件再发起 → 任务行显示文件名；思考期间不定进度条应平滑来回滚动（不停在起点抖动）
11. 错误处理：断网或填错 Key 发起检查 → 侧边栏底部常驻红字错误 + 重试按钮，恢复网络后点重试应成功并清除错误；改写失败同理（面板内错误行 + 重试）
12. 范围统一：重启 Obsidian 后范围选择器应记住上次选择（默认「选中」）；无选区时检查/改写均提示先选中；切「全文」后底部输入框提示应变为「…改写全文…」；选一段文字输入改写要求 → 只改写选中部分；全文改写超过 3 万字应被拒绝并提示
13. 首次改写：新会话第一次改写（思考期最长）不应出现满屏红——等待期面板只有状态行（「正在连接/思考中…」），输出后从未改写处逐句推进，未改写到的原文不标红
14. 提供商管理：设置 → 添加提供商（如 OpenAI 预设）→ 填该家的密钥 → 测试连接；切回 DeepSeek 应仍用 DeepSeek 的密钥正常检查（两家密钥互不影响）；删除非当前提供商；旧扁平设置首次加载应自动迁移且密钥保留
15. 密钥加密：配置密钥后打开插件目录 data.json → apiKey 应为 `enc:` 开头的密文（桌面端）；侧边栏底部只显示 token/耗时统计，不再有 ¥ 金额；「获取模型列表」应列出该服务商可用型号并可点选
