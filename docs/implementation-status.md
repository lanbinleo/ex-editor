### 真机验收清单（用户操作）

1. 设置 → ExEditor：确认预设与模型名（DeepSeek 应为 deepseek-flash）；试一下「测试连接」
2. 选中一段文字 → 命令「检查选中文字」或右键菜单；侧边栏应出现该范围的建议
3. 打开一篇长文 → 命令「检查全文」：底部过程行应显示批次进度；思维链开启时可见「思考中… N 字」增长
4. 全文检查中途点侧边栏「取消」或命令「取消进行中的检查」：应立即停止且无残留状态
5. 检查完成后底部常驻一行用量（GLM 只显示总量与耗时属正常）
6. 观察：新建议卡片有淡入上移动画，忽略/接受后卡片淡出；悬停卡片与按钮有过渡

### 当前限制（已知，按 roadmap 后续里程碑解决）

- 建议为内存态：重启 Obsidian 后清空（重新检查即可恢复）
- 无编辑器内波浪线标记（M4）；无三层次检查强度与指令重写（M3）；无批量接受（M3，需先有快照）
- 全文分批顺序执行，长文耗时较长（并发在候选，M5 评估）
- 流式依赖 fetch：若服务商 CORS 拦截则自动降级非流式（功能不受影响，无过程显示）
- 流式下 400 重试、json mode 自动降级已保留，但流式 + response_format 的服务商兼容性需真机覆盖
