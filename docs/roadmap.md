# 路线图 — ExEditor

原则：**不要一口吃成一个胖子。** 每个里程碑独立可用、可真机验证、完成后版本号递增；未列出的能力一律先记入「候选」不做。

## 里程碑

### M0 (0.1.0) 骨架 ✅ 2026-09-28

- 官方 sample plugin 重建为 ExEditor，独立 Git 仓库
- 构建 / 类型检查 / 单测 / lint 管线就绪
- 文档体系（AGENTS、README、docs 四件套）与 legacy 存档
- 验收：插件能在 Obsidian 加载，冒烟命令可执行

### M1 (0.2.0) 最小安全闭环 ✅ 2026-09-28

- 移植纯核心模块 `validate` / `protected` / `apply` / `diff` / `parse` + 全部单测（41 个）
- 「检查本段落」命令：OpenAI 兼容单提供商（DeepSeek/GLM 预设 + 自定义）
- 设置页：baseURL / API Key / 模型 / 测试连接
- 侧边栏 v1：建议列表（精确更新架构），逐条接受（单事务、可撤销）/ 忽略
- 验收：真实 vault 中检查一段含错别字的文字，接受建议后文字正确替换，Ctrl+Z 撤销，全程无错替换

### M2 (0.3.0) 检查范围与过程反馈 ✅ 2026-09-28

- 检查范围三种：本段落 / 选中文字（无选区回落段落）/ 全文（按空行段落分批，每批约 3000 字，顺序执行）
- 全程可取消（AbortController）：侧边栏取消按钮 + 命令；批间检测到文档被修改则中止而非错位检查
- 流式传输：fetch + SSE（`src/llm/sse.ts` 纯函数解析器），思考过程逐字反馈；requestUrl 非流式兜底
- 过程信息行：侧边栏底部小字——检查中显示批次/思考字数/已收条数，完成后常驻 思考tok·总tok·耗时（GLM 无思考 token 时自动省略）
- 思维链控制设置：跟随默认 / 开启 / 关闭 / 按力度（thinking / reasoning_effort 参数）
- 预设修正：DeepSeek 模型名改 `deepseek-flash`（deepseek-chat/reasoner 已于 2026-07 停用）
- CSS 动效：卡片进离场、hover 与状态过渡（120–180ms，安静克制）
- 右键菜单基础项：检查选中文字 / 检查本段落
- 验收：真实 vault 中选区与全文检查走通；全文检查中途取消无残留；流式时可见思考字数增长

### M3 (0.4.0) 修改层次与指令重写 ✅ 代码完成 2026-09-28（待真机验收）

- 检查强度三档：错别字标点（最小修改）/ 病句+错别字（当前默认）/ 深度润色建议——都走建议列表
- 按指令重写：侧边栏输入自定义要求，整段重写 → 行级+字符级 diff 预览 → 确认应用（应用前自动快照）
- 快照备份管理：vault 内目录、列表、恢复、每篇保留上限
- 批量接受/忽略（尊重当前筛选），单事务一次 Ctrl+Z 全撤
- 验收：重写整段后可从快照完整恢复；批量接受一次撤销；旧插件 editing-suggestions 至此可停用

### M4 (0.5.0) 编辑器内标记

- CM6 StateField 波浪线（按类别分色），随编辑自动重定位、失效标 stale
- 悬浮卡片：字符级 diff + 解释 + 接受/忽略（复用卡片组件）
- 右键菜单（标记上：接受/忽略）；状态栏待处理计数
- 验收：连续输入/删改时标记不错位、不残留；跨行建议正常显示与替换

### M5 (0.6.0+) 打磨

- 闲置段落自动检查（默认关，可配置触发间隔）
- 长文档性能与内存复查；提供商预设补全（Kimi/OpenAI/Ollama）；全文分批并发评估
- 用量显示开关；发布评估（社区市场：英文 README、审核要求）——是否发布届时决定

## 候选（未排期）

- 多语言校对（英文语法）
- 建议的忽略词典/白名单
- 全文分批并发请求（当前顺序执行）

## 版本约定

M0=0.1.0，此后每个里程碑 +0.1.0（M1=0.2.0 …）；里程碑内的修复用 patch。版本号只通过 `npm version` 变更。
