# 0.4.2 — 回退 :has 选择器改动

> **English TL;DR:** Reverts the `button:has(.ex-btn-icon)` → class-selector change introduced in 0.4.1, which regressed button layout. The stylesheet and button code are restored byte-for-byte to the state shipped and user-accepted in 0.4.0. No other changes.

## 修复

- 回退 0.4.1 中 `:has` → `ex-icon-btn` 类选择器的改动：按钮布局恢复原状（`styles.css` 与 `src/view/sidebar.ts` 还原至 0.4.0 状态）
- 社区目录的 `:has` 告警按「有意保留」处理：该选择器仅作用于侧边栏内部小范围子树，且此写法随 0.4.0 通过真机验收
