# 0.4.1 — 社区目录审核反馈修复

> **English TL;DR:** Release-hygiene update for the Obsidian Community directory submission: manifest description rewritten (no "Obsidian", ends with a period), the legacy read-only archive removed from the repository (it tripped the directory's static analysis without being part of the build), a `:has()` selector replaced with a plain class, and releases are now built and attested by GitHub Actions from source with the committed lockfile. No functional changes.

## 修复

- manifest 描述重写：移除 "Obsidian"（目录上下文已隐含）、以半角句号结尾、动词开头
- 移除仓库内的 `legacy/writingbuddy/` 旧项目存档：目录审核会静态扫描全仓库，存档代码的告警（如 `onunload` detach leaf、直接设样式）被误报为插件问题；存档不参与构建，已删除（历史提交仍可查阅）
- `styles.css` 以类选择器 `ex-icon-btn` 取代 `button:has(.ex-btn-icon)`，避免 `:has` 广谱失效的性能告警
- 发布改为 GitHub Actions（`.github/workflows/release.yml`）：从源码 + lockfile 构建、三绿校验、manifest 版本与 tag 一致性校验、生成工件构建来源证明（artifact attestation）后附产物

无功能变化；插件行为与 0.4.0 完全一致。
